# PlaylistVault Browser Handoff

Load this folder unpacked from Chrome/Edge extensions with Developer mode enabled.

- Direct media files (MP4/WebM/audio/M3U8) download in-browser via the
  `downloads` permission — no desktop app needed.
- Watch pages (YouTube/Udemy) hand off to the local `playlistvault://`
  protocol so the desktop engine (yt-dlp) handles them.
- It has no cookie, browsing-history, or external network permissions.
